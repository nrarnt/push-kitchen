# Push Kitchen

A calm kitchen puzzle game. Push ingredients over chopping boards and stoves, combine them, and serve each hatch the dish it wants. There is no timer and no way to lose: every move can be undone.

**Play it in your browser: https://nrarnt.github.io/push-kitchen/**

It needs a keyboard.

| Key | Does |
|---|---|
| Arrows or WASD | move the chef |
| Z | undo |
| R | restart the kitchen |
| Enter | next kitchen, once this one is solved |
| Esc | back to the menu |

Written in Rust with [Bevy](https://bevy.org), as a way to learn Rust. [docs/design.md](docs/design.md) describes the rules, the level file format and how the code is laid out.

## Running it

```
cargo run               # on your computer
cargo test              # the puzzle rules and the game logic
tools/build_web.sh      # builds the browser version into web/dist
tools/publish_web.sh    # puts web/dist on GitHub Pages
```

The sprites and sounds in `assets/` are original, generated by `tools/make_sprites.py` and `tools/make_sounds.py`.
